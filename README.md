# Il tuo team di agenti AI

Il kit del workshop «Il tuo team di agenti AI» di Alessio D'Aleo.

Un team guidato da **Leo, il Capo dello Staff**, con Ada (ricerca), Giulia (marketing), Marco (vendite), Sara (clienti) e Vito (revisore). Si personalizza sulla tua azienda partendo dal tuo sito.

## Scarica

Dalla pagina [Releases](../../releases/latest):

- **Strada A** (Claude Pro o superiore, VS Code): `team-di-agenti-kit.zip`. Decomprimi, apri la cartella in VS Code e segui `PROMPT.md`.
- **Strada B** (piano gratuito, claude.ai): `team-di-agenti-skill.zip`. Caricalo così com'è in Impostazioni → Funzionalità → Skill.

## Le regole del team

- Gli agenti preparano bozze: niente parte senza il tuo ok.
- Un dato che manca diventa «da verificare», mai inventato.
- Niente dati personali di clienti o pazienti nelle richieste.
