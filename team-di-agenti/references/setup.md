# Setup del team

Create or update the profile (location: see stato.md).

## Regole
- Never invent anything: write only what the user said, or what their own website says (see «Dal sito»). A missing answer becomes `[DA COMPLETARE]`.
- Keep the user's own words: do not rephrase, expand or complete them (no added nouns, units or details). Only fix punctuation and capitals.
- Never delete information the user did not ask to change.

## Se il profilo esiste già
Apply ONLY the requested changes (Edit the affected sections), then show a 3-line summary of what changed. Stop.

## Dal sito
When the user gives their website ("configura il team dal mio sito: …"), read it first (WebFetch the home page and at most 3 linked pages such as chi siamo, servizi, contatti). If you cannot open it, say so in one line and do the interview.
- Fill only «Attività», «Offerta», «Tono di voce» and «Canali» from the site. Copy what the site says, short; end each such bullet with `(dal sito, da verificare)`.
- Never take from the site: «Clienti ideali», «Obiettivi», «Regole»: ask them.
- Never write prices, numbers or names the site does not show.
- Before the questions, show in at most 6 lines what you found, then ask the missing questions as below, skipping those the site already answered.

## Se non esiste
1. Use the answers already in the user's message. Ask the missing ones ONE AT A TIME, in this order:
   1. "Di cosa si occupa la tua attività? (cosa fai, dove, quante persone)"
   2. "Chi sono i tuoi clienti ideali?"
   3. "Cosa vendi? I prodotti o servizi principali."
   4. "Come devono suonare i tuoi testi? (es. caldo, diretto, elegante)"
   5. "Cosa vuoi ottenere nei prossimi 90 giorni?"
   6. "Su quali canali comunichi?"
   7. "C'è qualcosa che il team non deve MAI fare o dire?"
   8. "Attiviamo tutti i ruoli (Ricercatore, Marketing, Vendite, Clienti, Revisore) o ne spegniamo qualcuno?"
   9. "Modalità leggera (consigliata sul piano gratuito: max 2 ruoli per lavoro) o completa?"
   10. "Vuoi dare un nome diverso ai tuoi agenti? (Leo, Ada, Giulia, Marco, Sara, Vito)" (optional, asked last: skip it if the user said not to ask questions; no answer = keep the default names)
2. Write the profile from `profilo-template.md`, keeping every heading exactly as written and in the same order. `revisore` is always `sì`. `## Nomi del team`: write the heading and its comment, then ONLY the lines for names the user chose (e.g. `- vendite: Luca`). If the user chose none, leave the section with no name lines (an absent line means the agent keeps its default name). Never write `[DA COMPLETARE]` or the default names there.
3. Close with: "Fatto, il tuo team è pronto. Prova: «Capo, prepara il piano della settimana». Per un agente su misura per il tuo settore: «proponimi degli agenti»."
